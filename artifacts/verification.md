# 검증 기록

- 엔진: Vitest 24개 테스트 통과. 7-bag, 모든 블록 회전, 충돌, SRS 벽차기, 착지 가이드, 하드/소프트 드롭, 고정 지연, 홀드 제한, 자동 상태 전환, 게임오버, 재시작, 1~4줄 삭제, 콤보, Back-to-Back, All Clear, 레벨, T-Spin.
- 빌드: TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- 브라우저: PC 방향키·회전·홀드·하드 드롭·일시정지, 모바일 조작 버튼, 게임오버 및 재시작 확인.
- 반응형: 320 / 375 / 414 / 768 / 1440px 확인. 320px에서 문서 너비와 클라이언트 너비 모두 305px로 가로 넘침 없음(15px 스크롤바 포함 환경). 320~414px, 높이 812px에서 게임 중 터치 버튼 하단은 뷰포트 내부.
- 도움말: 열기, Esc 닫기, 이펙트 토글 확인. 사운드 설정이 새로고침 후 유지됨.
- 렌더링: 최초 레이아웃과 글꼴 로드 후 정적 블록 미리보기 재그리기 확인. 브라우저 오류 로그 없음.
- 연출: 실제 엔진/렌더러로 4줄 삭제 800점, 팩맨 스윕과 색상별 파편을 중간 프레임에서 시각 확인. 임시 검증 페이지는 제거함.
- 의존성: 테스트 도구를 수정 버전으로 업데이트한 후 npm audit 취약점 0건.

`mobile-320.png`는 모바일 시작 화면, `line-clear-verified.png`는 줄 삭제 연출 검증 캡처다.
